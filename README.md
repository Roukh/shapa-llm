# shapa

Memory and a work ledger for coding agents. Each wiki keeps one SQLite file of features, jobs, tasks and memory, rule and issue rows; harness hooks recall, capture corrections and prune after every merge.

    curl -fsSL https://raw.githubusercontent.com/Roukh/shapa-llm/main/bootstrap.sh | sh

Wiki rules: `shapa/assets/AGENTS.md`. Contributing: `AGENTS.md`. MIT.
